## 一、竞赛规则解析

### 1.1 创意赛流程

```
形式审查（8/20-9/6提交） → 复赛（会议评审，评三等奖+入围决赛） → 决赛（现场演示+答辩，评一二等奖）
```

**形式审查材料**：作品简介、功能需求说明、系统设计说明、演示文档、视频、图片、源程序

**决赛要求**：
- 现场演示实物系统
- 抽签答辩，**隐匿学校/队名/指导教师信息**
- 1 名队员主讲，介绍作品 + 演示实物 + 回答专家提问
- 入围但缺席决赛 → 取消资格

### 1.2 评分方法

- 去掉最高分和最低分，计算平均分
- 平均分相同 → 按原始平均分排序
- **满分 100 分**，7 个维度综合打分

## 五、竞争对手分析

| 类型 | 典型作品 | 我们的优劣 |
|------|---------|-----------|
| 智慧农业 | 传感器+自动灌溉+ NB-IoT 上报 | 我们缺传感器种类和 IoT 协议，但多模态+可视化更强 |
| 智能家居 | ESP32+语音控制+App | 他们有 MQTT/BLE，我们系统完整度更高 |
| 环境监测 | 传感器网络+大屏 | 他们传感器多，我们分析深度更深 |
| 智慧医疗 | 穿戴设备+健康监测 | 他们硬件集成度高，我们软件工程能力更强 |

**我们的核心差异点**：不是"接几个传感器亮个灯"，而是**从感知到分析到反馈的完整智能闭环**。答辩时要打这张牌。

## 八、结论

**当前水平：三等奖稳，二等奖悬。**

差距不在技术深度（YOLO+多模态+评分模型在本科竞赛里够用了），而在**"物联网"三个字的体现**。评委看的是：

1. 你是不是把"物"（Pi、摄像头、麦克风）联成了"网"（不只是单机上传）
2. 你的"平台"能不能管多个设备（不只是单个 Pi 的数据展示）
3. 你的系统有没有 IoT 该有的通信协议（MQTT/CoAP，不只是 HTTP）

**如果这三个问题在答辩时回答不好，很容易被评委定性为"这就是个 AI 视觉项目，不是物联网项目"。**

补齐设备管理页 + MQTT 心跳 + 围绕 IoT 叙事重新包装，是从三等奖冲到二等奖的关键。

## 四、IoT 叙事话术（答辩用）

> 我们的作品不是简单的"AI课堂分析"，而是 **"边缘智能 + 云边协同的物联网教育平台"**。
>
> - **感知层**：树莓派搭载摄像头+麦克风阵列，实时采集课堂音视频数据，YOLO行为检测在边缘端完成，不依赖云端
> - **网络层**：MQTT 心跳 + HTTP 批量上传，设备在线状态实时可监控，离线时本地缓存不丢数据
> - **平台层**：管理员端统一管理多教室设备，设备心跳、在线率、采集量一目了然
> - **应用层**：五维课堂评分模型 + 多模态分析 + 教师/管理员双端可视化
>
> 这符合物联网"全面感知、可靠传输、智能处理"的核心理念。

## 五、现场答辩预案

| 可能问题 | 回答要点 |
|---------|---------|
| IoT 体现在哪？ | 边缘端本地推理不做纯上传、设备管理平台、MQTT心跳 |
| 和市面上产品区别？ | 私有化部署、边缘端处理保护隐私、面向高校课堂定制 |
| YOLO 是你们训练的吗？ | 使用预训练模型，但评分模型/事件提取规则引擎是自主开发 |
| 准确率怎么样？ | 准备对比数据：分析结果 vs 实际情况 |
| 能接多个教室吗？ | 架构支持多Pi多教室，管理员端统一管理 |
| AI工具使用比例？ | YOLO预训练模型约30%，业务逻辑/评分/前端均为自主开发 |

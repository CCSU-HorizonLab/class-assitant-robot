## 二、详细改动

### 2.1 作品简介文档（`docs/作品简介.md`）

**背景**：文档用于竞赛形式审查提交，需支持 PDF 导出。

**改动**：
- 添加 `@page { size: A4; margin: 20mm 15mm; }` 规则，控制 PDF 页面尺寸
- 新增 `@media print` 块，覆盖 Typora/VS Code/GitHub 等常见渲染器的容器高度限制
- 修正 "三层协同 of" → "三层协同的"（翻译残留）
- Mermaid 图中 C4 节点描述更新为完整技术栈
- 语音交互创新点描述增强（补充 DeepSeek-V3 细节）
- 新增第七章「人工智能工具辅助开发说明」

### 2.2 系统架构图（`docs/architecture.png`）

**背景**：部分 PDF 导出工具不支持 Mermaid 渲染，代码块会显示为原始文本。

**解决**：使用 mermaid-cli 预渲染为 PNG，导出 PDF 时如果 Mermaid 无法渲染可替换为图片。

### 2.3 专注度硬编码 fallback 修复

**问题**：YOLO 未产出区域专注度数据时，管线用 MD5 hash 生成 0.76~0.86 的伪随机值作为 `avg_attention_ratio`，`attention_curve` 也用 hash 生成伪正弦波。所有 36 个 session 的专注度数据看起来合理但全部不可信。

**改动**（`classroom_feedback_pipeline.py`）：

| 函数 | 改动前 | 改动后 |
|------|--------|--------|
| `_resolve_avg_attention_ratio` | 无数据时 `hash → 0.76~0.86` | 返回 `None` |
| `_build_attention_curve` | 无数据时 `hash → 正弦波` | 返回 `None` |
| 主流程 `attention_score` | `round(ratio * 100, 2)` 始终有值 | `None` 当 ratio 为 None |
| 主流程 `feedback_score` | 硬编码权重 `0.45×att + 0.4×resp + 0.15×act` | 动态权重：专注不可用时重分配至响应+活跃；全部不可用时返回 `None` |

**影响**：
- 所有现有 session 的 `attention_score` 从假数值变为 `null`
- JSON 输出中 `avg_attention_ratio` 和 `attention_curve` 变为 `null`
- 前端自动适配（见 2.4）

### 2.4 前端评分体系统一

**问题**：
- Hero 卡片和 Phase 3.2 面板展示不同分数，用户困惑
- `formatScore(null)` 显示为 `0.0`，无法区分"零分"和"无数据"
- 无数据时所有图表仍展示误导性内容

**改动**（`dashboard_v11.py`）：

| 改动项 | 说明 |
|--------|------|
| Hero 卡片标签「综合反馈分」→「综合评分」 | 命名统一 |
| Python 详情面板「反馈分」→「综合评分」 | 前后一致 |
| `formatScore(null/undefined)` → `—` | 视觉区分无数据和零分 |
| 新增 `attention_unavailable` 显示标记 | `attention_score is None` 时触发 |
| 专注度不可用时自动隐藏 | Phase 3.2 面板、区域专注图、注意力曲线 |
| `avg_attention_ratio` 为 None 时隐藏 | 平均专注率指标 |
| `attention_curve` 为 None 时隐藏 | 专注度时间线 |

## 三、音频分析链路确认

本轮排查确认了系统音频分析的完整链路：

```
Pi 端采集 → transcript_delivery.py（Azure STT / Vosk / Chat Cache 三层转写）
         → teacher_questions.py（规则引擎提取提问）
         → teacher_transcript.json + teacher_questions.json
         → 本地端管线消费
```

当前所有 session 语音指标为 0 的原因：**Pi 端没有麦克风设备**，`audio.wav` 无有效音频输入，三层转写全部返回空。这是硬件限制，非代码缺陷。Pi 接入麦克风后链路即可正常产出语音数据。
